# Make It Sound Natural 1.2.0

First stable macOS release. Bring your own OpenRouter, OpenAI, Anthropic,
or compatible provider API key; provider usage is billed by that provider.

- Rewrite selected text using global shortcuts and paste a chosen variant back.
- Configure providers, models, request speed, and optional app/screenshot context.
- Set up Accessibility and optional Screen Recording through onboarding.
- Receive stable updates through a separate Sparkle channel.

Download the `.app.zip` or `.dmg`, move **Make It Sound Natural.app** to
Applications, then launch it. The existing app icon is retained.

API keys are stored in macOS Keychain and sent to the configured provider for
request authentication. Submitted text and enabled context are sent directly
to that provider. OpenRouter can route requests to underlying model providers.
See the repository's [privacy policy](https://github.com/make-it-sound-natural/misn-desktop/blob/master/PRIVACY_POLICY.md).
